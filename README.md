# 잘되면 밥한끼 Web v0

HTML + CSS + JavaScript 기반 기획용 웹 프로토타입입니다.

## 파일 구조

- index.html : 메인 홈페이지
- apply.html : 소개 신청서
- css/style.css : 디자인
- js/main.js : 꽃잎, 사진 미리보기, 기획용 폼 제출

## 실행 방법

VS Code에서 폴더를 연 뒤 `index.html`을 브라우저에서 실행하세요. Live Server를 사용하면 편합니다.

## 현재 일부러 구현하지 않은 것

- 실제 회원가입/로그인
- Supabase/DB
- 휴대폰 인증
- 관리자 페이지
- 실제 매칭 시스템
- 이용약관/개인정보처리방침 본문
- 후원 결제

## 수정 포인트

색상은 `css/style.css`의 가장 위 `:root`에서 쉽게 바꿀 수 있습니다.
