# 대.세.는 소개팅

> 대전·세종에서 실제 만남을 연결하는 운영자 심사형 소개팅 서비스

## 프로젝트 소개

**대.세.는 소개팅**은 신청자가 작성한 정보와 원하는 상대 조건을 운영자가 직접 검토하고, 서로 잘 맞을 가능성이 있는 두 사람에게 소개를 제안하는 서비스입니다. 대전·세종 생활권의 소규모 운영을 전제로 MVP를 개발하고 있습니다.

운영 웹사이트: [daese-sogating.vercel.app](https://daese-sogating.vercel.app/)

## 시작한 이유

많은 프로필을 탐색하거나 오랫동안 앱 안에서 채팅하는 방식보다 실제로 만날 수 있는 사람을 신중하게 연결하는 데 집중하고자 시작했습니다. 전국 단위 서비스와 경쟁하기보다 이동과 만남이 쉬운 대전·세종 지역에 범위를 좁히고, 운영자가 직접 신청자를 확인하는 방식으로 방향을 정했습니다.

## 서비스 방식

서비스는 다음 흐름으로 운영하는 것을 목표로 합니다.

**신청 → 운영자 심사 → 소개 제안 → 양측 수락 → 만남 → 상호 동의 후 연락처 교환**

서비스 내부 채팅이나 무작위 프로필 탐색은 제공하지 않습니다. 신청 내용과 조건을 바탕으로 운영자가 소개 대상을 선정합니다.

## 핵심 기능

- 기본 정보와 원하는 상대 조건을 포함한 소개 신청
- 프로필 사진 등록과 프로필 카드 미리보기
- Cloudflare Turnstile을 이용한 자동 입력 방지
- Supabase를 통한 신청 정보와 비공개 사진 저장
- 관리자 전용 로그인과 신청서 조회
- 신청 승인·미승인, 관리자 메모, 정보 삭제

## 현재 개발 상태

웹사이트의 신청 접수부터 관리자 심사까지 필요한 기본 흐름을 구현했습니다. Vercel에 웹사이트를 배포했고 Supabase 데이터베이스, Storage, Auth, Edge Functions 및 Cloudflare Turnstile을 연결했습니다.

현재 실제 운영 전 통합 점검과 운영 절차 정리가 필요한 MVP 단계입니다. 전화번호 PASS 인증은 아직 적용하지 않았습니다.

## 기술 스택

- 프론트엔드: HTML, CSS, Vanilla JavaScript
- 백엔드: Supabase Edge Functions
- 데이터베이스·인증·파일 저장: PostgreSQL, Supabase Auth, Supabase Storage
- 자동 입력 방지: Cloudflare Turnstile
- 배포: Vercel, GitHub
- 실험용 앱 환경: Expo, React Native, TypeScript

## 로컬 실행

Node.js가 설치된 환경에서 저장소를 내려받고 다음 명령을 실행합니다.

```bash
npm install
npm run website
```

명령 실행 후 터미널에 표시된 로컬 주소로 접속합니다.

Expo 실험 앱을 실행하려면 다음 명령을 사용합니다.

```bash
npm start
```

## 앞으로 만들 것

- 실제 신청부터 심사 결과 처리까지 전체 흐름 점검
- PASS 기반 전화번호 본인 인증
- 소개 제안과 양측 수락 절차
- 심사 결과 및 진행 상황 안내
- 개인정보 보유기간에 따른 자동 삭제와 운영 도구
- 실제 운영 피드백을 반영한 신청·심사 경험 개선
