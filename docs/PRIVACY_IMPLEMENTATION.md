## 11. 운영 차단 상태

점검 당시 원격 API가 `enabled:true`여서 사용자 요청과 달랐다. Supabase의 `APPLICATIONS_ENABLED`만 false로 변경한 뒤 공개 API가 `enabled:false`, `testMode:false`로 응답함을 확인했다. 다른 Secret이나 기존 신청 데이터는 변경하지 않았다.

격리된 로컬 가상 데이터 테스트 예외는 유지되지만 Edge에서는 해당 예외가 적용되지 않는다.
원격은 이전 동의 버전 `2026-09-07`이며, 새 로컬 버전은 `2026-09-07-v1`이다. 새 코드·SQL은 아직 배포하지 않았다.
